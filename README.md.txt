# AI Resume Screening Agent

An AI-powered agent that analyzes resumes against a job description,
scores candidates using NLP similarity, ranks them, and provides
AI-generated reasoning for each score.

## Project Status
🚧 Under development.

## Planned Features
- Resume parsing (PDF/DOCX/TXT)
- Job description skill extraction
- NLP similarity scoring
- Candidate ranking
- AI-generated reasoning
- CSV/JSON output
